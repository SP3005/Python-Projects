# Interactive Personal Data Collector

A simple Python program that collects personal information and displays the entered data with its data type and memory address.

## Features

* Collects name, age, height, and favorite number
* Displays data types using `type()`
* Displays memory addresses using `id()`
* Calculates approximate birth year

## Concepts Used

* Variables
* `input()` and `print()`
* `int()` and `float()`
* `type()` and `id()`
* f-strings
* `datetime`
* Arithmetic operations
