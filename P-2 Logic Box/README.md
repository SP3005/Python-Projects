# Pattern Generator and Number Analyzer

## Project Description

This is a Python menu-driven program that allows users to generate different patterns and analyze a range of numbers.

## Features

### Pattern Generator

The program can generate:

* Right Triangle
* Inverted Right Triangle
* Pyramid
* Inverted Pyramid
* Diamond Pattern
* Hollow Square
* Butterfly Pattern

The user can select a pattern and enter the number of rows.

### Number Range Analyzer

The user enters a starting and ending number.

The program:

* Checks each number as Even or Odd.
* Calculates the sum of all numbers in the range.
* Shows an error message for an invalid range.

## Python Concepts Used

* `while` loop
* `for` loop
* Nested loops
* `if-elif-else`
* `match-case`
* `range()`
* `input()`
* Modulus operator `%`

## Assumptions

* The user enters valid integer values.
* The number of rows is positive.
* The starting number is less than or equal to the ending number.
* Python 3.10 or above is required for `match-case`.
